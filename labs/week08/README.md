# Week 8: Assessment and SQL consolidation

## Environment and portfolio

Use the **BS0030 Core** Codespace configuration from your existing student fork. Sync the fork before opening or rebuilding the appropriate environment. The Core container supports SQLite and Node; the Kotlin and Go configurations support Weeks 9–10 and 11–12 respectively.

From a terminal run:

```bash
sqlite3 --version
```

Commit your source and explanations under `labs/week08/work/`. Markdown code blocks below are the starter source: copy the indicated block into the named file, then edit your working copy. Generated jars, executable binaries and disposable database files are not submission evidence.

## Assessment block

The midterm covers Weeks 1–7 and introduces no new paradigm. Follow Moodle for the approved duration, permitted aids and submission mode. Use [the preparation guide](../../assessments/midterm-preparation.md) beforehand. Actual paper questions and keys are instructor-only.

## Independent consolidation after assessment

Use the Week 7 fixture. Write a query that returns one row per book with its number of active loans, including books with zero. Then find members who have ever borrowed a computing book, without duplicate members. Predict outputs and explain the grain of each result.

Keep this formative work in `labs/week08/work/`. It introduces no new assessed syntax. Review one functional closure example and one Prolog search trace, then write the mechanism you found most difficult.

## Next unit
